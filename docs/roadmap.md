# Roadmap

## Phase 0: Foundation

- Prepare Java, PostgreSQL, Git, and Maven.
- Configure Spring Boot profiles.
- Add PostgreSQL, Flyway, JPA, Validation, and Actuator.
- Add local Docker Compose database.
- Document architecture and setup.

## Phase 1: Users And Auth

- Create user entity and migration.
- Add registration and login.
- Hash passwords securely.
- Issue JWT access tokens.

## Phase 2: Chat Model

- Add guilds, channels, memberships, and messages.
- Add REST endpoints for initial client screens.
- Add pagination for message history.

## Phase 3: Realtime

- Authenticate WebSocket connections.
- Send and receive messages over WebSocket.
- Add presence, typing indicators, and read state.

## Phase 4: Clients

- Build Android client with Kotlin.
- Build desktop client with Compose Multiplatform.

## Phase 5: Calls

- Add WebRTC signaling.
- Add voice rooms.
- Add video calls.
